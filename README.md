# Fine-Grained Cat Breed Recognition with Global Context Vision Transformer

## 📄 Publication

M. P. Hera et al.
IEEE International Conference on Computer and Information Technology (ICCIT) 2025
[IEEE Xplore Paper](https://ieeexplore.ieee.org/document/11490185) | 
arXiv Paper: [https://arxiv.org/abs/2602.07534](https://arxiv.org/abs/2602.07534)

### Key Contributions:

* Developed GCViT-Tiny for fine-grained classification
* Achieved 94.54% validation accuracy
* Advanced augmentation + class-wise analysis
* Built Hugging Face demo application

---

## 🔬 Research Project: FGVC of Pet Breeds

* Evaluated GCViT-Tiny on Oxford-IIIT Pet dataset (37 classes)
* Achieved 92.5% Top-1 accuracy (5-run average)
* Conducted ablation studies and comparison with CNN & ViT
* Used Grad-CAM and attention visualization for interpretability
* Demonstrated strong performance in fine-grained recognition
